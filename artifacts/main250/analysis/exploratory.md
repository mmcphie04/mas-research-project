# main250 — EXPLORATORY analyses (200 questions)

**Everything in this file is exploratory** (outside `docs/MAIN250_ANALYSIS_SPEC.md`). Brackets: 95% percentile intervals, 10,000 question resamples (seed 0); ratios resample questions. Scores: exact expected accuracy under random tie-breaking. Readout probabilities: the stored letter distributions, fp32_head head, readout batch size 1.

**Measured property of the readouts that limits sections 2 and 6:** in 99.2% of the 2,000 pool states the readout puts more than 0.99 on one option, and in 99.2% that option is the agent's own stated answer. The readout is taken after the response, so it largely restates the answer: Δp(correct) nearly equals Δ correctness, rules a and b nearly reproduce plurality, and rule c's 'most confident' agent is mostly a near-tie at ≈ 1 among agents.
